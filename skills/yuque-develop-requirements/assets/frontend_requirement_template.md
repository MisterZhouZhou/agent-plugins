# 功能需求

> 二级标题按"页面 / 弹窗 / 公共组件"维度组织，不要复用 PRD 章节号。
> PRD 中散落在各章节的规则（字段、校验、状态、显隐、跳转、文案）按"哪个页面用得到"分发到对应页面下。
> 综合 PRD + 设计稿提炼：有正式设计稿时，页面样式与页面功能均以设计稿为准（PRD/原型是方案意图，设计稿是最终要实现的效果）；无设计稿再用原型。跨页业务规则（准入、状态机语义、金额口径、互斥）仍从 PRD 提炼并贴到对应页面。
> `设计稿：` 优先填该页最具体的 Figma 子链接（含 node-id）。PRD 只有完整功能模版总入口时，须做帧↔页面映射后写入各页，禁止各页统一占位只挂一个总入口。帧名与画面不一致时以画面为准。
> 映射不到或确实没有设计稿时，才用占位：<设计稿地址：xxx场景>。页面创建路径、接口路径、字段命名等同理：<页面创建路径>、<接口路径>、<字段名>。
> 原文档已经明确的链接/路径/字段必须原样保留，不要替换成占位。
